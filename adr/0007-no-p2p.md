# 0007. No P2P or decentralized contribution

**Status:** Accepted
**Date:** 2026-09-13

## Context

Policy analysis is expensive and per-site, so sharing results between users would grow coverage far
faster than any single user could. A decentralized store was proposed: users contribute analyses,
everyone reads them.

## Decision

Not doing it.

## Consequences

- The local-first claim survives intact. A network layer would change what the product is, not just
  what it does, and would contradict record 0001.
- Domain-keyed analyses leak browsing interest. For a rare domain, an entry reveals that somebody
  looked it up, which is close to identifying them. Batching and k-anonymity reduce this without
  removing it.
- It is an attack path, not a moderation nuisance. A contributed fake good grade inflates a WSS,
  and an inflated WSS can make the PII gate exempt a phishing site at the moment credentials are
  typed.
- It would create permanent content-moderation and takedown obligations for a project that
  currently has no server to host anything.
- The alternatives for contributing are ToS;DR's reviewed process, or a manual export the user
  chooses to share.
